# RASTRO-LINK v0.1.0

Herramienta local para organizar y representar visualmente entidades, relaciones y evidencias de una investigación.

## Uso

1. Abre `index.html` en Chrome, Edge o Firefox.
2. Pulsa **Añadir entidad** para registrar teléfonos, SIM, IMEI, personas, cuentas u otros datos.
3. Pulsa **Vincular** y selecciona primero el origen y después el destino.
4. Utiliza las fichas laterales para documentar fuentes, fechas, estado, notas e imágenes.
5. Exporta periódicamente una copia JSON del caso.

La herramienta funciona en el navegador y no envía la información a servidores. El guardado automático utiliza el almacenamiento local del navegador.

## Funciones principales

- Grafo editable con arrastre, zoom, búsqueda y filtros.
- Entidades configurables mediante color, forma, estado, relevancia, etiquetas e imágenes.
- Relaciones dirigidas, bidireccionales o no dirigidas, con estilos y trazabilidad.
- Vistas de grafo, inventario y análisis estructural.
- Guardado automático local, deshacer y rehacer.
- Importación JSON y CSV/TSV.
- Exportación JSON, CSV, PNG, HTML autónomo y PDF mediante impresión.

## Privacidad

Los archivos exportados pueden contener información sensible. Revisa siempre el contenido y aplica las medidas de protección adecuadas antes de compartirlo.
